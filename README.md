# AstroVoice

Озвучка книг для личной читалки владельца (astrolog-lev.ru/chitalka/, только для него) голосом Vosk «male_1».

Здесь только сценарий GitHub Actions — `.github/workflows/voice.yml`. Программа озвучки (`tools/audio_book.py`) и тексты
книг лежат в закрытом репозитории AstroLearning; сценарий берёт их оттуда во время работы и нигде не публикует.
Репозиторий открытый, потому что для открытых репозиториев GitHub даёт минуты без ограничений, а голос медленный:
большая книга — около 18 часов работы одной машины. Здесь книга делится на части (до 20), и их читают столько же машин
одновременно — около часа на большую книгу. Вся озвучка — здесь (с 21 октября 2026); в AstroLearning своей нет.

Как работает (каждый час сам и вручную: Actions → «Озвучка книг» → Run workflow; в поле «book» можно указать, какую книгу
озвучить первой — часть названия):

1. **Что озвучить** — спрашивает у сервера, какие книги отмечены «Озвучить» (`audio-list`), и выбирает одну.
2. **Части 1…N** — каждая машина озвучивает свой кусок (~70 тысяч знаков, частей не больше 20) и передаёт его
   дальше зашифрованным.
3. **Склеить и отправить** — собирает запись и разметку предложений и отправляет в читалку (`audio-put`).

Журналы видны всем, поэтому в них только названия книг и проценты — без текста.

## Секреты

Settings → Secrets and variables → Actions → New repository secret:

- `ASTROLEARNING_TOKEN` — fine-grained токен GitHub: доступ только к AstroLearning, Contents — Read-only
  (тот же, что секрет `GITHUB_TOKEN` в блокноте Colab).
- `BOOKS_SSH_KEY` — ключ books-deploy (на сервере `cat ~/.ssh/books-deploy`, всё от `-----BEGIN` до `END…-----`),
  тот же, что секрет `BOOKS_SSH_KEY` в AstroLearning.
